# Taller: Exploración computacional de la regresión logística

## Objetivo
Estudiar computacionalmente propiedades concretas del modelo logístico mediante experimentos reproducibles y resultados cuantitativos.

## Integrantes
- Oscar Joya y Monica Lopez

## Estructura del Proyecto
- `src/`: Código modular (modelo, optimización, simulación).
- `notebooks/`: Cuaderno ejecutable (`experimentos.ipynb`) con los 5 ejercicios.
- `resultados/`: Figuras generadas (superficies, curvas de nivel, ajustes).
